실전 예제 모음

✨ 모션 그래픽 & 애니메이션

텍스트 리빌과 로딩 애니메이션을 통해 키프레임·마스크·트랙 매트의 기초를 익힙니다.

실전 예제 1: 마스크를 이용한 텍스트 리빌 애니메이션

텍스트가 선 뒤에서 자연스럽게 나타나는 타이틀 애니메이션을 제작하며 셰이프 레이어와 트랙 매트를 익힙니다.

  1. [텍스트 생성] 새 컴포지션을 만든 뒤 문자 도구(T)를 사용해 제목(예: MOTION GRAPHICS)을 입력합니다.
  2. [리빌 라인 생성] 레이어 > 새로 만들기 > 셰이프 레이어를 선택하고 펜 도구(G)로 텍스트 중앙에 직선을 그립니다.
  3. [트랙 매트 설정] 타임라인에서 트랙 매트(TrkMat) 옵션을 표시하고 텍스트 레이어의 트랙 매트를 알파 매트 '셰이프 레이어 1'로 지정합니다.
  4. [애니메이션 적용] 텍스트 레이어를 선택한 뒤 P로 위치 속성을 열어 0초와 2초에 키프레임을 추가해 선 아래에서 위로 이동하도록 조정합니다.
  5. [결과 확인] 재생해 보면 텍스트가 선 뒤에서 부드럽게 등장하는 리빌 애니메이션이 완성됩니다.
실전 예제 2: 셰이프 레이어로 로딩 아이콘 만들기

Trim Paths 기능을 이용해 선이 그려졌다가 사라지는 반복 애니메이션을 구성합니다.

  1. [셰이프 레이어 생성] 레이어 > 새로 만들기 > 셰이프 레이어를 추가합니다.
  2. [원 그리기] 타원 도구로 원을 드래그하되 Fill은 없음, Stroke는 원하는 색과 두께로 설정합니다.
  3. [선 다듬기 추가] 셰이프 레이어의 추가(Add) 버튼에서 선 다듬기(Trim Paths)를 선택합니다.
  4. [애니메이션] 선 다듬기 1에서 끝(End) 값을 0%→100%, 이어서 시작(Start) 값을 0%→100%로 키프레임을 배치해 선이 그려졌다가 지워지도록 만듭니다.
  5. [무한 반복] 마지막 키프레임의 스톱워치를 Alt 키로 클릭해 loopOut() 표현식을 입력하면 끊김 없이 반복됩니다.

🧪 시각 효과(VFX) & 합성

트래킹과 크로마키 기법으로 다른 화면을 입히거나 그린 스크린 배경을 치환합니다.

실전 예제 3: 코너 핀 트래킹으로 화면 합성

스마트폰 화면에 다른 영상을 자연스럽게 합성하며 원근 트래킹을 연습합니다.

  1. [소스 준비] 배경 영상과 합성용 영상을 타임라인에 배치합니다.
  2. [모션 추적] 배경 영상을 선택해 창 > 추적기 패널에서 동작 추적(Track Motion)을 클릭하고 추적 유형을 원근 코너 고정으로 변경합니다.
  3. [추적점 배치] 나타난 네 개의 추적점을 스마트폰 화면 모서리에 정확히 위치시킵니다.
  4. [분석] 추적기 패널에서 앞으로 분석(Analyze Forward)을 눌러 움직임을 분석합니다.
  5. [데이터 적용] 대상 편집(Edit Target)으로 합성용 레이어를 지정하고 적용(Apply)을 누르면 영상이 화면을 따라가며 합성됩니다.
실전 예제 4: Keylight로 그린 스크린 제거

그린 스크린 배경을 제거하고 다른 장면과 합성하는 기본 크로마키 워크플로우입니다.

  1. [소스 배치] 타임라인 아래쪽에 배경 영상을, 위쪽에 그린 스크린 인물 영상을 배치합니다.
  2. [Keylight 적용] 효과 및 사전 설정에서 Keylight (1.2)를 검색해 인물 클립에 적용합니다.
  3. [스크린 컬러 선택] 효과 컨트롤에서 Screen Colour 스포이드를 사용해 녹색 배경을 클릭합니다.
  4. [가장자리 다듬기] Screen Matte를 열어 Clip Black과 Clip White 값을 조정해 가장자리를 정리합니다.
  5. [결과 확인] 재생해 자연스럽게 배경이 치환되었는지 확인합니다.

🧊 3D 공간 연출

3D 레이어와 카메라를 이용해 입체감 있는 전환과 텍스트 연출을 구현합니다.

실전 예제 5: 카드 플립 전환 만들기

여러 이미지를 3D 공간에 배치하고 순차적으로 뒤집히는 애니메이션을 만듭니다.

  1. [3D 레이어 전환] 이미지 레이어의 3D 스위치를 활성화합니다.
  2. [공간 배치] 각 레이어의 위치(Position) Z 값을 조정해 앞뒤로 배치합니다.
  3. [플립 애니메이션] R로 회전 속성을 열고 Y 회전에 키프레임을 추가해 순차적으로 -180° 회전시키며 카드가 뒤집히는 효과를 만듭니다.
  4. [카메라 추가] 레이어 > 새로 만들기 > 카메라를 추가해 통합 카메라 도구(C)로 시점을 조정합니다.
  5. [조명 연출] 레이어 > 새로 만들기 > 조명을 추가해 그림자와 입체감을 더합니다.
실전 예제 6: 3D 텍스트와 카메라 워크

CINEMA 4D 렌더러를 활용해 텍스트에 두께를 주고 카메라가 주변을 도는 연출을 만듭니다.

  1. [렌더러 변경] 컴포지션 설정에서 3D 렌더러를 CINEMA 4D로 변경합니다.
  2. [3D 텍스트 준비] 텍스트 레이어를 만들고 3D 스위치를 켠 뒤 도형 옵션의 돌출 깊이 값을 높여 두께를 줍니다.
  3. [카메라 컨트롤러 설정] 3D Null 개체와 카메라를 생성하고 카메라를 Null에 패런팅합니다.
  4. [애니메이션] Null 개체의 Y 회전에 0초 0°, 5초 360° 키프레임을 주면 카메라가 텍스트 주위를 한 바퀴 돕니다.

🤖 AI 자동화

Adobe Sensei 기반 기능으로 배경 제거와 방해물 삭제 작업을 자동화합니다.

실전 예제 7: 내용 인식 채우기로 방해물 제거

풍경 영상에서 지나가는 사람·차량 등을 AI로 지워 매끄러운 장면을 얻습니다.

  1. [마스크 설정] 펜 도구로 제거할 물체를 감싼 뒤 마스크 패스에 키프레임을 추가해 움직임을 따라갑니다.
  2. [마스크 모드 변경] 마스크를 빼기(Subtract)로 바꿔 해당 영역을 투명하게 만듭니다.
  3. [AI 채우기 실행] 창 > 내용 인식 채우기 패널에서 채우기 방법을 개체로 두고 채우기 레이어 생성을 클릭합니다.
  4. [결과 확인] 생성된 채우기 레이어로 물체가 자연스럽게 제거되었는지 확인합니다.
실전 예제 8: 로토 브러시 2로 인물 분리

움직이는 인물만 추출해 다른 배경과 합성하는 자동 로토스코핑 워크플로우입니다.

  1. [로토 브러시 실행] 분리할 영상을 더블 클릭해 레이어 패널에서 연 다음 로토 브러시 도구를 선택합니다.
  2. [영역 지정] 첫 프레임에서 인물 안쪽을 녹색으로 칠하고, 포함된 배경은 Alt를 누른 채 붉은색으로 제외합니다.
  3. [AI 전파] 스페이스바를 눌러 프레임을 진행하면 AI가 자동으로 외곽선을 따라갑니다.
  4. [결과 확인] 컴포지션 뷰로 돌아와 인물만 분리된 것을 확인하고, 아래에 새 배경을 배치합니다.

제작 효율을 높이는 루틴

01. 컴포지션 설계

  • 프로젝트 패널에서 폴더를 모듈별(소스, 프리컴프, 프리셋)로 나눠 정리합니다.
  • 작업 전 프레임 레이트와 해상도를 확정하고, 미리보기 해상도를 1/2로 낮춰 퍼포먼스를 확보합니다.

02. 모듈별 제작

  • 모션 그래픽 요소는 각기 프리컴포지션으로 관리해 재사용성을 높입니다.
  • VFX·AI 작업은 독립된 프리컴프에서 먼저 완성한 뒤 메인 컴포지션으로 가져옵니다.

03. 검수 & 렌더

  • 기본 그래프 편집기로 속도 곡선을 정리하고, 모션 블러를 켠 상태로 최종 미리보기를 확인합니다.
  • Adobe Media Encoder 대기열을 활용해 여러 버전을 한 번에 렌더링합니다.

마지막 체크 포인트

  • 표준 색 공간 유지: 프로젝트 설정에서 작업 색 공간을 통일하고, 필요 시 LUT를 프리컴프 단계에서 적용합니다.
  • 캐시 관리: 편집 > 환경 설정 > 미디어 & 디스크 캐시에서 캐시 저장 위치를 SSD로 지정해 미리보기 속도를 높입니다.
  • 버전 관리: 중간 저장 시 컴포지션 이름 뒤에 v1, v2 등 버전을 붙여 변경 사항을 명확히 추적합니다.
