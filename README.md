# MBC AI 마스터클래스 - 개선된 웹사이트

## 📖 프로젝트 개요

MBC 아카데미의 **[미디어 프론티어] 생성형 AI 마스터 클래스 과정**을 위한 통합 학습 플랫폼입니다. 생성형 AI 도구들을 활용한 미디어 콘텐츠 제작 방법을 체계적으로 학습할 수 있도록 설계되었습니다.

## 🚀 주요 개선사항

### ✨ 새로운 기능들

- **🎯 진행률 추적**: 학습 진도를 실시간으로 확인하고 관리
- **🧭 통합 네비게이션**: 일관된 사용자 경험과 직관적인 페이지 이동
- **📱 완전 반응형**: 모든 디바이스에서 최적화된 학습 환경
- **🎨 현대적 UI/UX**: 다크 테마와 인터랙티브 요소들
- **⌨️ 키보드 단축키**: 효율적인 학습을 위한 단축키 지원
- **📑 동적 목차**: 언제든 접근 가능한 사이드바 목차

### 🛠️ 기술적 개선사항

- **통합된 CSS 시스템**: CSS 변수 기반의 일관된 디자인 시스템
- **모듈화된 JavaScript**: 재사용 가능한 컴포넌트 구조
- **성능 최적화**: 효율적인 리소스 로딩과 애니메이션
- **접근성 향상**: WCAG 가이드라인 준수

## 🎨 디자인 시스템

### 색상 팔레트
```css
:root {
  /* 메인 컬러 */
  --primary: #007acc;        /* 브랜드 블루 */
  --primary-hover: #0056b3;  /* 호버 상태 */
  --success: #28a745;        /* 성공/완료 */
  
  /* 다크 테마 */
  --bg-primary: #121212;     /* 메인 배경 */
  --bg-secondary: #1e1e1e;   /* 카드/사이드바 */
  --bg-tertiary: #2a2a2a;    /* 강조 영역 */
  
  /* 텍스트 */
  --text-primary: #e0e0e0;   /* 메인 텍스트 */
  --text-secondary: #b3b3b3; /* 보조 텍스트 */
}
```

### 타이포그래피
- **폰트**: Apple System Fonts, Noto Sans KR
- **스케일**: 반응형 타이포그래피 스케일
- **가독성**: 적절한 행간과 자간 설정

### 컴포넌트
- **버튼**: 3가지 스타일 (Primary, Secondary, Home)
- **카드**: 호버 효과와 그라디언트 강조
- **네비게이션**: 브레드크럼과 진행률 표시
- **모달/사이드바**: 부드러운 애니메이션

## 🎮 인터랙티브 기능

### 진행률 추적
```javascript
class ProgressTracker {
  - 현재 페이지 자동 감지
  - 로컬 스토리지 기반 진행률 저장
  - 시각적 진행률 표시
  - 완료된 페이지 마킹
}
```

### 네비게이션 시스템
```javascript
class NavigationManager {
  - 키보드 단축키 (Alt + 방향키)
  - 자동 이전/다음 페이지 감지
  - 브레드크럼 자동 업데이트
  - 홈 버튼 상대 경로 계산
}
```

### 목차 관리
```javascript
class TOCManager {
  - 동적 목차 생성
  - 현재 페이지 하이라이트
  - 터치/클릭 인터랙션
  - 반응형 사이드바
}
```

## 📱 반응형 디자인

### 브레이크포인트
- **Desktop**: 1200px+
- **Tablet**: 768px - 1199px
- **Mobile**: 320px - 767px

### 적응형 레이아웃
- **그리드 시스템**: CSS Grid와 Flexbox 조합
- **유연한 타이포그래피**: clamp() 함수 활용
- **터치 친화적**: 44px+ 터치 타겟 크기

```bash
# Python 3.x

php -S localhost:8000
```

## 📋 사용법

### 기본 네비게이션
- **홈 버튼**: 언제든 메인 페이지로 돌아가기
- **이전/다음**: 순차적 학습 진행
- **브레드크럼**: 현재 위치 확인

### 키보드 단축키
- `Alt + ←`: 이전 페이지
- `Alt + →`: 다음 페이지  
- `Alt + Home`: 메인 페이지
- `Esc`: 목차 사이드바 닫기

### 진행률 확인
- **헤더 프로그레스 바**: 전체 진행률
- **목차 체크마크**: 완료된 섹션 표시
- **자동 저장**: 브라우저 종료 후에도 진행률 유지

## 📞 지원 및 문의

### 기술 지원
- 브라우저 호환성: Chrome 90+, Firefox 88+, Safari 14+
- 모바일 지원: iOS 12+, Android 8+

### 문제 해결
1. **페이지가 로드되지 않는 경우**: 웹 서버 실행 확인
2. **스타일이 적용되지 않는 경우**: CSS 파일 경로 확인
3. **JavaScript 오류**: 개발자 도구 콘솔 확인
4. **진행률이 저장되지 않는 경우**: 브라우저 로컬 스토리지 설정 확인
