서비스별 워크플로우

🎤 Suno AI

간단한 설명만으로 보컬 트랙과 연주곡을 빠르게 제작하고, Remix로 스타일을 바꿔봅니다.

예제 1: 편안한 카페 배경음악 만들기

보컬 없이 잔잔한 피아노 연주곡을 생성해 공부·카페 분위기에 활용합니다.

  1. [모드 선택] Create 화면에서 Instrumental 옵션을 켭니다.
  2. [스타일 입력] Style of Music에 Calm and cozy cafe jazz piano라고 입력합니다.
  3. [생성] Create 버튼을 누르고 생성된 두 버전 중 원하는 트랙을 선택해 다운로드합니다.
예제 2: 80년대 댄스 보컬곡 제작 (AI 가사)

장르와 분위기를 지정하고 자동 생성된 가사로 완성형 보컬곡을 만듭니다.

  1. [커스텀 모드] Custom Mode 스위치를 켜고 보컬 옵션을 활성화합니다.
  2. [가사 주제] Lyrics 입력란에 A song about dancing all night in a retro city를 입력합니다.
  3. [스타일 제안] 장르 필드에 80s synthwave dance, upbeat, energetic라고 적고 생성해 결과를 비교합니다.

🎧 Udio

고품질 보컬과 길이 확장 기능을 활용해 완성형 음원을 만든 뒤 다른 스타일로 재가공합니다.

예제 1: 감미로운 R&B 보컬곡 만들기

도시 감성의 R&B 곡을 생성하며 보컬 품질을 확인합니다.

  1. [프롬프트] Prompt에 A soulful R&B song about walking in the city on a rainy night, male vocal을 입력합니다.
  2. [가사 옵션] Lyrics를 Auto-generated로 두어 AI가 가사를 작성하게 합니다.
  3. [생성] Create를 눌러 생성된 결과를 확인하고, 마음에 드는 take를 저장합니다.
예제 2: Extend 기능으로 곡 길이 늘리기

30초 클립을 기반으로 추가 구간을 생성해 곡 전체를 확장합니다.

  1. [기준 트랙 선택] 예제 1에서 생성한 곡을 선택하고 Extend 버튼을 클릭합니다.
  2. [길이 설정] 추가하고 싶은 구간(앞부분/뒷부분)과 길이를 지정합니다.
  3. [생성 & 검토] 새로운 파트를 생성해 전체 곡이 자연스럽게 이어지는지 확인합니다.
예제 3: Remix로 분위기 바꾸기

기존 곡을 바탕으로 어쿠스틱 버전을 만들어 장르를 전환합니다.

  1. [Remix 실행] 재구성할 트랙에서 Remix 버튼을 클릭합니다.
  2. [새 스타일 입력] 프롬프트에 Acoustic folk version, gentle guitar and piano처럼 원하는 분위기를 입력합니다.
  3. [비교] 원곡과 Remix 결과를 비교해 프로젝트 톤에 맞는 버전을 선택합니다.

🎼 Stable Audio

Text-to-Audio로 BGM을, Audio-to-Audio로 효과음을 제작해 영상·게임 사운드를 구성합니다.

예제 1: 브이로그용 어쿠스틱 BGM 생성

여행 브이로그에 어울리는 밝은 포크 스타일 배경음을 만듭니다.

  1. [프롬프트] Prompt에 Uplifting and cheerful acoustic folk, ukulele, light percussion, for a travel vlog를 입력합니다.
  2. [길이 조절] Duration 슬라이더로 필요한 길이를 선택합니다.
  3. [생성] Generate 버튼을 눌러 결과를 확인하고 루프가 필요한 경우 Loop 옵션을 활용합니다.
예제 2: 영상 효과음(SFX) 제작

장면에 필요한 특정 효과음을 텍스트로 묘사해 생성합니다.

  1. [프롬프트] 효과음을 구체적으로 설명합니다. 예: Futuristic user interface click, soft, clean, UI feedback.
  2. [샘플링] 짧은 길이(2~4초)로 생성하여 필요한 만큼 다운로드합니다.
  3. [트림] 결과가 길다면 편집 툴에서 일정 부분만 잘라 사용합니다.

프로덕션 루틴

01. 프롬프트 설계

  • 장르, 악기, 분위기를 3요소로 구분해 작성하고, BPM이나 키(Key)가 필요하면 함께 명시합니다.
  • 참고 트랙이 있다면 링크나 곡명을 포함해 모델이 참고할 수 있도록 합니다.

02. 결과 비교

  • 각 서비스가 기본적으로 2개 이상의 take를 제공하므로, 메모를 남기며 비교 청취합니다.
  • 보이스가 필요 없는 경우 Suno/Udio의 보컬을 끄고 인스트루멘탈만 활용합니다.

03. 후반 작업

  • EQ와 컴프레션으로 레벨을 정리하고, 루프 구간은 크로스페이드로 이어줍니다.
  • 저작권 정책을 확인해 상업적 사용 범위를 프로젝트별로 기록합니다.

활용 팁

  • 버전 관리: 생성한 트랙 이름에 tool_date_version 규칙을 적용해 비교가 쉽도록 정리합니다.
  • 레퍼런스 확보: 상업 프로젝트는 각 도구의 라이선스 정책 캡처본을 함께 보관해 검수 시점을 명확히 합니다.
  • DAW 연동: 최종 믹싱은 Ableton, Logic 등 DAW에서 수행하며, 필요 시 스템(Stem) 분리 옵션을 활용해 레이어를 개별 컨트롤합니다.
